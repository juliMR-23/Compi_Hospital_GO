# Hospital de los Costeños con Narcolepsia


Sistema de gestión hospitalaria para el Hospital de los Costeños con Narcolepsia desarrollado en Go (Golang 1.21+). Demuestra el uso de orientación a objetos idiomática en Go mediante composición de structs (Person), polimorfismo con interfaces (Attender), encapsulamiento por paquetes, constantes tipadas (iota) y manejo estricto de errores

> [!NOTE]
> Proyecto de Lenguajes y Compiladores desarrollado por Julián Marín Ramírez
